# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0.0 | No |

---

## Local Data Privacy Statement

FocusShell is designed from the ground up as a **100% local-first application**:
- All activity logs, project names, window titles, and statistics are stored strictly in your local user directory (`~/.local/share/focusshell/focus.db`).
- FocusShell performs zero network calls, contains zero telemetry, and transmits zero data to external servers or third parties.

---

## Reporting a Vulnerability

If you discover a security issue, privilege escalation vulnerability, or data leakage flaw in FocusShell, please report it privately:

- **Email**: [rainebriars@gmail.com](mailto:rainebriars@gmail.com)
- **Subject**: `[SECURITY] Vulnerability Report for FocusShell`

Please provide:
1. A clear description of the vulnerability.
2. Steps to reproduce or a minimal proof of concept.
3. Affected versions and system environment (Linux distribution, display server).

We will acknowledge receipt within 48 hours and work with you on a resolution before any public disclosure.
